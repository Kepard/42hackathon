# HoloSpeed — hackathon project description

HoloSpeed turns Minecraft into a live demonstration of Holo4-powered computer use.
H Company’s Holo4 reads gameplay screenshots and structured observations, chooses
progression objectives, and revises the plan when execution fails. TypeSafe AI’s
Jev checks proposals against fresh game state and selects routine actions, while
a custom Fabric bridge and Baritone execute navigation, mining, crafting,
smelting, and portal construction through normal game interactions. Local outcome
checks verify inventory changes and progression. The dashboard shows the live
game, actual Holo4/Jev decisions and latency, granular milestones, and shared
controls. Gladia lets viewers pause, steer objectives, or ask Holo4 questions
by voice. Devin turns recorded failures into reviewed investigations and proposed
regression tests. The current challenge is an autonomous, from-scratch route from
an empty inventory to the Nether.
